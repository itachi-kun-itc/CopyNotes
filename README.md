# CopyNotes

入力したテキストをすぐコピーできる、軽量なメモアプリ。画面はGitHub Pages、ログイン・共有APIはCloudflare Pages FunctionsとD1で動作します。

公開URL：https://itachi-kun-itc.github.io/CopyNotes/

Cloudflare側：https://copynotes-bjx.pages.dev/（同じ最新版の画面と共有API）

## 使い方

- **端末**：このブラウザだけのメモ。入力内容は自動保存し、クラウドへ送信しません。
- **共有**：管理コマンドで発行済みの半角数字5桁の番号を入力。同じ番号の端末で同じメモにアクセスします。先頭が0の番号も使えます。未発行・削除済みの番号は無効です。
- **同期**：共有タブの追加・編集・削除を送信し、他の端末の最新内容も取得します。端末タブでは無効です。
- **更新**：共有内容を取得。未同期の自分の編集も保持します。「更新」「同期」は共有タブでのみ操作できます。
- ログイン中は、共有メモの追加・編集・削除を入力が約0.8秒落ち着いてから自動送信し、共有タブを表示中は約5秒ごとに他端末の変更を取り込みます。空欄を追加しただけでは送信しません。画面の復帰・ネット接続の回復時も自動で再開し、通信失敗時は間隔を空けて再試行します。ログアウト・セッション切れで停止します。
- 共有メモを空白・改行・全角スペースだけにして同期すると、削除として扱い、本文のレコードをDBから除去します。復活防止用の本文を含まない削除情報だけを別途保持します。削除の同期中に再び文字を入力した場合は、新しいメモとして保護します。
- 共有メモは同期した順に上から表示。新しい同期は下へ追加し、再同期したメモも最後へ移動します。
- 同時編集が重なった場合は、相手の版を残し、自分の編集は未同期の別メモとして保持します。古い版からの削除は適用しません。
- 通信に失敗したときは未同期の変更をこのブラウザに保存し、再度「同期」で送信できます。番号を切り替えても下書きは番号ごとに保持します。
- リロード時・終了時・バックグラウンド移行時は、空欄や空白文字だけの入力欄を削除し、残った欄を上に詰めます。強制終了などで終了処理が呼ばれなくても次回起動時に整理します。共有済みの空白欄は削除待ちとし、次回の「同期」で他端末にも反映します。
- 未ログインで共有タブを開いても番号入力は表示しません。「ログイン」ボタンを押したときだけ番号入力を開きます。
- 「ログイン中」を押すと「ログアウト」ボタンだけを表示します。メニューの外側やEscで閉じられます。

番号を知っている人が、その番号の共有メモを閲覧・編集できる方式です。番号は共有相手に伝えて使います。

GitHub Pages版は第三者Cookieに依存せず、15分間のセッションを画面のメモリ内だけで使います。認証トークンはブラウザのストレージへ保存せず、再読み込み・画面終了後は再ログインが必要です。Cloudflare版は従来どおりHttpOnly Cookieでログイン状態を保持します。共有先のデータは共通、端末メモはそれぞれのサイト・ブラウザ内に保存されます。

## 番号の発行・削除（VS Codeの管理用ターミナル）

公開画面や公開APIには番号の発行機能はありません。このプロジェクトの管理コマンドを、Cloudflareにログインした環境から実行します。

```sh
# 新しい5桁番号を自動発行
npm run login:issue

# 指定した番号を発行（例。実行したときだけ発行されます）
npm run login:issue -- 12345

# 番号を削除し、その番号でログイン中の端末も解除
npm run login:delete -- 12345

# すべての番号・ログイン状態を削除
npm run login:delete-all

# 発行済み番号数とログイン状態の件数を確認
npm run login:status
```

`--local` を付けると、Cloudflareではなくローカル起動用の番号を管理します（例：`npm run login:issue -- 12345 --local`）。本番・ローカルは別の台帳です。既に発行済みの番号は上書きしません。

以前の「任意の5桁でログイン」した番号は自動登録しません。番号削除後は既存Cookieも無効です。同じ番号を後日再発行すると新しい共有先を作り、過去の共有内容を復元しません。

## メモの操作

- 「＋」で入力欄を追加し、右側のマークでコピー。追加直後は入力欄に自動フォーカスしません。
- 入力欄の高さは本文に合わせて自動調整します。起動・再表示・表示幅やフォントの変更後にも再計算し、保存済みの長い文章も全体を表示します。
- HTTP／HTTPSのURLと `www.` から始まるURLは青い下線付きで表示し、押すと別タブで開きます。入力欄にフォーカスがある間は文字の選択・編集を優先します。編集を終えて欄の外を押すとリンクを開けます。
- アプリ全体で拡大・縮小を抑止し、文字の選択は入力欄だけで許可します。
- 上部の操作バー・端末／共有タブ・同期状態は固定し、その上でのホイール・タッチスクロールを抑止します。スクロールバーとスクロール操作の対象はメモ欄だけです。ページ全体のスクロールと端での引っ張りも抑止します。
- パソコンは右クリック →「削除」、iPad・スマートフォン等のタッチ機器は右から左へ入力欄をスワイプしきると削除します。途中で離すと元に戻り、縦スクロール・複数の指・文字選択中の操作では削除しません。削除後は下のメモが滑らかに上へ詰まります（動きを減らす設定にも対応）。
- Shift+F10 でも削除メニューを開き、Esc で閉じられます。
- Python・JavaScript・TypeScript・HTML・CSS・JSON・SQL を判定して VS Code Dark+ 配色で表示。
- Enter で自動インデント、括弧・引用符・HTML 終了タグを補完。Tab／Shift+Tab で1行・選択した複数行を字下げ・字上げできます。Esc → Tab で入力欄から移動します。
- 複数行の貼り付けはインデントを調整。Python は元のブロック構造を保持します。

## ローカル起動

Node.js 24 以降で `npm start` を実行し、http://127.0.0.1:4173 を開きます。追加パッケージは不要です。`COPYNOTES_PORT` でポートを変更できます。

ローカルでの共有先はテスト用の `.local-data/copynotes.sqlite` です。本番で端末間共有する場合は、すべての端末で同じ Cloudflare の公開URLを開いてください。端末メモと共有下書きはブラウザのローカルストレージ、ログイン状態は HttpOnly Cookie に保存します。

## Cloudflare

- Pages プロジェクト：`copynotes`
- D1 データベース：`copynotes-db`（バインディング名 `DB`）
- Functions：`functions/api/[[path]].js`
- DB スキーマ：`migrations/`（共有メモ・発行済み番号の台帳）

公開時は、画面だけの変更も含めてGitHub PagesとCloudflare Pagesの両方を同じ最新版に更新します。mainへのpushでGitHub Actionsがテスト・ビルドし、GitHub Pagesへ公開します。Cloudflare側も `npm run deploy:api` で公開してください。コミット済みの最新版を両方へ再公開する場合は `npm run deploy` を使えます。GitHub Pagesだけの再公開は `npm run deploy:pages` です。

```sh
npm run check
npm test
npm run build:pages
```

共有APIのスキーマを変更した場合は、Cloudflare認証後に `npm run db:migrate` を実行してから公開します。`npm run deploy:api` はCloudflare側の画面と共有APIをまとめて更新します。

`npm run build:pages` は公開用ファイルだけを `dist/` へコピーし、`app-config.js` にCloudflareの公開API URLを設定します。`npm run build` はCloudflare／ローカル用の同一オリジン設定です。SQLite・セッション・テスト・管理用コマンドはアップロードしません。APIはGitHub Pagesの正確なオリジンだけにCORSを許可します。

Cloudflare のローカルランタイムは `npm run cloud:dev`。利用する場合は別途 `npx --yes wrangler@4.156.0 d1 migrations apply copynotes-db --local` でスキーマを適用してください。
